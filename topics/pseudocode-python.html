Textbook 9.1 · pp. 217–219

Computational thinking skills

Before writing any code, a programmer has to understand the problem and plan a solution. The textbook names four skills.

SkillWhat it meansExample
AbstractionKeep only the details needed to solve the problem; leave out everything else.A road map keeps road names and junctions but leaves out buildings and trees. A rail map keeps only stations and lines.
DecompositionBreak a large problem into smaller parts that are easier to solve, and solve each one.A school system is split into attendance, timetable and grades modules.
Pattern recognitionSpot parts that are the same or similar, so one solution can be reused.Drawing any regular polygon repeats "draw a side, turn" (Activity 9A).
Stepwise refinementBreak each step of an algorithm into smaller, more detailed steps until each one can be written as a single program statement."Enter time" → enter hours → check 2–8 → re-enter if invalid.

Exam tip (June 2024 P21 Q7a): when asked for an advantage of abstraction in a scenario, don't just give the definition. Say what it does for this problem, e.g. "only the data needed by the new module is stored, so the program is simpler to write and quicker to run."

Textbook 9.2 · pp. 219–235

Algorithms

An algorithm is an ordered set of steps that solves a problem. There are three ways to write one down.

MethodDescription
Structured EnglishNumbered steps in plain English with a limited set of words. It must be unambiguous, but it follows no fixed rules.
FlowchartA diagram of shapes joined by flow lines. Terminator = start/end; parallelogram = input/output; rectangle = process; diamond = decision, with Yes/No labels on its exits.
PseudocodeA precise, language-independent way to write an algorithm using agreed keywords such as INPUT, OUTPUT, IF, FOR and ←. Cambridge's style is set out in the Pseudocode Guide and the exam insert.

The three basic constructs

  • Sequence — statements run one after another.
  • Selection — IF or CASE chooses which statements run.
  • Iteration — FOR, REPEAT … UNTIL or WHILE … ENDWHILE repeats statements.

Translating structured English and flowcharts into pseudocode

The book works through a marathon runner example. Each English step becomes one or more pseudocode statements:

  1. "Enter …" → a prompt OUTPUT, then INPUT.
  2. "Calculate …" → an assignment with ←.
  3. "If … then …" → IF … THEN … ENDIF.
  4. "Repeat …" or "for each …" → a loop.
  5. "Output …" → OUTPUT.
// Marathon time: hours, minutes, seconds → total seconds
DECLARE Hours, Minutes, Seconds, MarathonSeconds : INTEGER
OUTPUT "Enter hours, minutes and seconds"
INPUT Hours
INPUT Minutes
INPUT Seconds
MarathonSeconds ← (Hours * 60 + Minutes) * 60 + Seconds
OUTPUT "Time in seconds is ", MarathonSeconds
New since 2024: you must also be able to go the other way, writing a flowchart or structured-English description from given pseudocode. Practice question P3 covers this.

Constants, variables and data types

A variable is a named value that can change while the program runs. A constant is a named value that cannot change. Declare everything before you use it, and give every variable a starting value.

DECLARE Radius : REAL
DECLARE Volume : REAL
DECLARE SurfaceArea : REAL
CONSTANT Pi ← 3.142

OUTPUT "Please enter the radius of the sphere"
INPUT Radius
WHILE Radius <= 0 DO
    OUTPUT "Please enter a positive number"
    INPUT Radius
ENDWHILE
Volume ← (4 / 3) * Pi * Radius * Radius * Radius
SurfaceArea ← 4 * Pi * Radius * Radius
OUTPUT "Volume is ", Volume
OUTPUT "Surface area is ", SurfaceArea

This follows the textbook's sphere example (Example 11.1). Python version:

PI = 3.142                      # Python has no true constants: CAPITALS by convention
radius = float(input("Please enter the radius of the sphere "))
while radius <= 0:
    radius = float(input("Please enter a positive number "))
volume = (4 / 3) * PI * radius ** 3
surface_area = 4 * PI * radius ** 2
print("Volume is", volume)
print("Surface area is", surface_area)

June 2024 P21 Q1(a): "Odd OR Even" is a STRING, because it is in quotation marks. Many candidates wrote BOOLEAN because they saw the word OR.
Identifier names: use meaningful names such as TotalMarks, not A or B. Single letters make code hard to understand and maintain, and are easy to mix up. Other good practice: comments, indentation, constants for fixed values, and initialising variables.

Textbook 9.2 (p. 224) and 11.2.1 · pp. 271–274

Selection: IF and CASE

Pseudocode
IF MyValue > YourValue
  THEN
    OUTPUT "I win"
  ELSE
    OUTPUT "You win"
ENDIF
Python
if my_value > your_value:
    print("I win")
else:
    print("You win")

In Cambridge style THEN usually goes on its own line, but writing it on the IF line is also accepted. Every IF must close with ENDIF. Nested IFs need one ENDIF for each IF.

Nested IF (there is no ELSEIF in Cambridge pseudocode)

IF Mark < 40
  THEN
    Grade ← "Fail"
  ELSE
    IF Mark < 60
      THEN
        Grade ← "Pass"
      ELSE
        IF Mark < 80
          THEN
            Grade ← "Merit"
          ELSE
            Grade ← "Distinction"
        ENDIF
    ENDIF
ENDIF

CASE: use it when ONE variable is tested against many values

CASE OF Choice
    1      : OUTPUT "Routine 1"
    2      : OUTPUT "Routine 2"
    3      : OUTPUT "Routine 3"
    4 TO 6 : OUTPUT "Routine not written"
    10     : OUTPUT "Exit"
    OTHERWISE : OUTPUT "Incorrect choice"
ENDCASE

A CASE clause can test a single value, a list ('a', 'e') or a range (4 TO 6). OTHERWISE catches anything else and must come last.

Python 3.10+ (match)
match choice:
    case 1: print("Routine 1")
    case 2: print("Routine 2")
    case 4 | 5 | 6: print("Routine not written")
    case _: print("Incorrect choice")
Python (any version)
if choice == 1:
    print("Routine 1")
elif choice == 2:
    print("Routine 2")
elif 4 <= choice <= 6:
    print("Routine not written")
else:
    print("Incorrect choice")
Common errors: writing CASE Choice (it must be CASE OF Choice); using ELSE instead of OTHERWISE; closing with ENDIF; leaving out the colon after a value.
June 2024 P21 Q5(b): to call an error routine for any other value, add the single line OTHERWISE : CALL Error(C) just before ENDCASE.

Iteration: three kinds of loop

LoopTypeWhen to useRuns at least once?
FOR … NEXTCount-controlledThe number of repeats is knownYes, if start ≤ end
REPEAT … UNTILPost-conditionValidation; must run at least onceAlways
WHILE … DO … ENDWHILEPre-conditionMay need to run zero timesNot necessarily
Pseudocode
Total ← 0
FOR Counter ← 1 TO 10
    OUTPUT "Enter a number"
    INPUT Number
    Total ← Total + Number
NEXT Counter
OUTPUT "The total is ", Total

FOR Counter ← 1 TO 10 STEP 2
    OUTPUT Counter      // 1 3 5 7 9
NEXT Counter
Python
total = 0
for counter in range(1, 11):     # 11, not 10!
    number = int(input("Enter a number "))
    total = total + number
print("The total is", total)

for counter in range(1, 11, 2):
    print(counter)               # 1 3 5 7 9
The biggest Python trap: FOR i ← 1 TO 10 includes 10. Python's range(1, 10) stops at 9. Try the Loop Visualiser in Simulations.

Validation: REPEAT is the better choice (textbook p. 274)

REPEAT … UNTIL — one INPUT
REPEAT
    OUTPUT "Enter value 0 to 10"
    INPUT Value
UNTIL Value >= 0 AND Value <= 10
WHILE — needs an INPUT before AND inside
OUTPUT "Enter value 0 to 10"
INPUT Value
WHILE Value < 0 OR Value > 10 DO
    OUTPUT "Enter value 0 to 10"
    INPUT Value
ENDWHILE

Notice the conditions are opposite. REPEAT stops when the value is valid; WHILE keeps going while it is invalid. Python has no REPEAT, so it uses while with the opposite condition, or while True: … break.

Nested loops (patterns, 2D arrays)

DECLARE Rows, Row, Col, Total : INTEGER
DECLARE Line : STRING
INPUT Rows
Total ← 0
FOR Row ← 1 TO Rows
    Line ← ""                      // reset for every row
    FOR Col ← 1 TO Row
        Line ← Line & "#"
    NEXT Col
    OUTPUT Line
    Total ← Total + Row
NEXT Row
OUTPUT "Total: ", Total

Textbook 11.3 · pp. 275–280

Procedures and functions

A procedure is a named block of statements that is defined once and can be called many times. A function is the same, but it always returns a value, so a function call is used inside an expression.

Procedure with a parameter
PROCEDURE Stars(Number : INTEGER)
    DECLARE Counter : INTEGER
    FOR Counter ← 1 TO Number
        OUTPUT "*"
    NEXT Counter
ENDPROCEDURE

CALL Stars(7)
Python
def stars(number):
    for counter in range(number):
        print("*", end="")

stars(7)
Function
FUNCTION Celsius(Temp : REAL) RETURNS REAL
    RETURN (Temp - 32) / 1.8
ENDFUNCTION

MyTemp ← Celsius(MyTemp)
Python
def celsius(temp):
    return (temp - 32) / 1.8

my_temp = celsius(my_temp)

By value vs by reference

PROCEDURE Celsius(BYREF Temperature : REAL)
    Temperature ← (Temperature - 32) / 1.8     // changes the caller's variable
ENDPROCEDURE
CALL Celsius(MyTemp)
BYVAL (default)BYREF
What is passedA copy of the valueThe address of the original variable
Can the procedure change the caller's variable?NoYes
PythonBehaves like by value for numbers and stringsNot directly: return the new value, or use a list

Header, parameters and arguments

  • Header: the first line. It gives the name, the parameters with their types, and (for a function) RETURNS type.
  • Parameter: the variable named in the header. Argument: the actual value passed in the call.
  • Arguments must match the parameters in number, order and data type.
  • A procedure call is a statement on its own (CALL). A function call goes on the right-hand side of an expression.
Examiner report, June 2024: candidates used OUTPUT where the function should RETURN a value, and left out ENDFUNCTION. Both lose marks.
Structure charts (Q7b, June 2024): if a module sends back one value, write it as a FUNCTION. If it changes a parameter (arrow going in and coming back out), use a PROCEDURE with BYREF. Example header: PROCEDURE SubA(Name : STRING, BYREF P2 : REAL).

Positions start at 1 in pseudocode but at 0 in Python. MID(S, 1, 1) is the first character; in Python that is s[0].

Looping through every character

Count ← 0
FOR i ← 1 TO LENGTH(Word)
    IF MID(Word, i, 1) = 'a'
      THEN
        Count ← Count + 1
    ENDIF
NEXT i

Password check (based on the textbook's Example 11.2)

CONSTANT StoredPassword ← "Secret"
DECLARE InputPassword : STRING
OUTPUT "Please enter your password"
INPUT InputPassword
IF LENGTH(InputPassword) = LENGTH(StoredPassword)
  THEN
    IF LEFT(InputPassword, 1) = LEFT(StoredPassword, 1) AND
       RIGHT(InputPassword, 1) = RIGHT(StoredPassword, 1)
      THEN
        OUTPUT "Correct first and last letters"
      ELSE
        OUTPUT "Password entered is incorrect"
    ENDIF
  ELSE
    OUTPUT "Password entered is incorrect"
ENDIF
June 2024 P21 Q8 (removing a comment): to look for "//", take two characters with MID(Line, i, 2), and loop only to LENGTH(Line) - 1 so that you never read past the end of the string.

1D and 2D arrays

An array is a data structure that holds several items of the same data type under one identifier. Each item is reached by its index. Cambridge arrays usually start at index 1.

DECLARE Names : ARRAY[1:30] OF STRING
DECLARE Board : ARRAY[1:3, 1:3] OF CHAR      // 2D: rows, columns

Names[1] ← "Ali"
Board[2, 3] ← 'X'

// Initialise a 2D array
FOR Row ← 1 TO 3
    FOR Col ← 1 TO 3
        Board[Row, Col] ← ' '
    NEXT Col
NEXT Row

Linear search

Found ← FALSE
Index ← 1
WHILE Index <= 30 AND Found = FALSE DO
    IF Names[Index] = SearchName
      THEN
        Found ← TRUE
      ELSE
        Index ← Index + 1
    ENDIF
ENDWHILE

Bubble sort

Top ← 9
REPEAT
    Swap ← FALSE
    FOR j ← 1 TO Top
        IF List[j] > List[j + 1]
          THEN
            Temp ← List[j]
            List[j] ← List[j + 1]
            List[j + 1] ← Temp
            Swap ← TRUE
        ENDIF
    NEXT j
    Top ← Top - 1
UNTIL NOT Swap OR Top = 0
June 2024 P21 Q4: to total the odd positions, test Index MOD 2, not Data[Index] MOD 2. The most common error was testing the array value instead of the index.

Python lists start at index 0: names = [""] * 30, board = [[" "] * 3 for _ in range(3)].

Textbook 10.3 · p. 249

Text files

Data in a text file is kept after the program ends. A file is opened in one of three modes: READ, WRITE (makes a new file, or replaces an existing one) or APPEND (adds to the end).

Pseudocode
DECLARE Line : STRING
DECLARE Count : INTEGER
Count ← 0
OPENFILE "Trees.txt" FOR READ
WHILE NOT EOF("Trees.txt")
    READFILE "Trees.txt", Line
    Count ← Count + 1
ENDWHILE
CLOSEFILE "Trees.txt"

OPENFILE NewFile FOR WRITE   // NewFile holds the name
WRITEFILE NewFile, "Hello"
CLOSEFILE NewFile
Python
count = 0
with open("Trees.txt", "r") as f:
    for line in f:
        line = line.strip()
        count = count + 1

new_file = "out.txt"
with open(new_file, "w") as f:
    f.write("Hello\n")
June 2024 P21 Q8(b): when the file name is held in a variable, do not put it in quotation marks (OPENFILE NewFile FOR WRITE). Always CLOSEFILE, and set any count to 0 before the loop.
