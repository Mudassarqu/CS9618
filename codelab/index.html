How the Code Lab works

  • Input box: programs can't pause to ask you questions, so type every value your program will INPUT, one per line, before pressing Run.
  • Pseudocode follows the Cambridge 9618 rules: capital keywords, ← for assignment, & to join strings, ENDIF, NEXT, ENDWHILE, ENDCASE. If you write Python by mistake, the error message tells you the pseudocode way.
  • It warns you if a variable isn't DECLAREd and stops you if you use a variable before giving it a value, just as an examiner would.
  • Python is real Python 3, running in your browser. The first run takes a few seconds to download.
  • Practice programs: Run tries your program with the example input. Check with tests runs every test case. Submit to teacher sends your code and test result to your teacher's sheet. Enter your name at the top first.
  • Your code is saved automatically in this browser, separately for each question and each language.
  • Shortcuts: Tab indents, Shift+Tab un-indents, Ctrl+Enter runs, and typing <- becomes ←.

Pseudocode features supported

DECLARE (including ARRAY[1:n] and [1:r, 1:c]), CONSTANT, INPUT, OUTPUT, IF/THEN/ELSE/ENDIF, CASE OF/OTHERWISE/ENDCASE (single values, lists, ranges with TO), FOR/TO/STEP/NEXT, WHILE/DO/ENDWHILE, REPEAT/UNTIL, PROCEDURE/CALL with BYVAL/BYREF, FUNCTION/RETURNS/RETURN, OPENFILE/READFILE/WRITEFILE/CLOSEFILE/EOF, plus LENGTH, LEFT, RIGHT, MID, TO_UPPER, TO_LOWER, NUM_TO_STR, STR_TO_NUM, IS_NUM, ASC, CHR, INT, RAND, ROUND, DIV, MOD.
